# Bacchus — handoff package

Read in this order:
1. SPEC.md — full production spec (stack, booking, notifications, hosting migration, build order, image manifest)
2. llms.txt — public agent-readable business summary (serve at /llms.txt)
3. Bacchus Homepage.dc.html — homepage prototype (source of truth for layout, copy, EN/GR strings, alt text)
4. Bacchus Book.dc.html — /book Google Ads landing + booking form → WhatsApp
5. Bacchus Brand Sheet.dc.html — colours, type, emblem usage
6. images/ — all photos and video (filenames are final; see manifest in SPEC.md)

The .dc.html files open in a browser (they load support.js from this folder). Inline styles are intentional — read them as the design tokens.
